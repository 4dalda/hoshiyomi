# 動画演出スキル — CapCut・Premiere向け

## 役割
YouTube Shorts・ヒーリングBGM動画の演出設計を担当する。
CapCut AIへの指示文を最適化された形で提供する。

## 基本演出テンプレート（星詠みChronicle版）

### ヒーリングBGM動画（60秒・9:16縦型）

```
【冒頭 0〜3秒】
- 真っ暗からフェードイン
- 曲名テキスト表示（中央・ゴールド・グロー発光）
- 3秒後にテキストがゆっくりフェードアウト

【本編 3〜57秒】
- 画像：ゆっくりズームイン（1.0→1.1倍・全編かけて）
- 画像：わずかにパン（左→右 または 右→左）
- エフェクト：シネマティックフィルター（薄め・彩度+10）
- テキストなし（BGMに集中させる）

【終盤 57〜60秒】
- 全体がゆっくりフェードアウト→真っ暗
```

## CapCut AI指示文テンプレート（コピペ用）

### 炎系（牡羊座・獅子座・射手座）
```
以下の演出で動画を仕上げてください。

冒頭3秒：「[星座名] ♈ [Hz]Hz Healing BGM」を
中央にゴールド色・グロー発光で表示し、
3秒後にフェードアウト。

画像：全編通じてゆっくりズームイン。
動きは最小限・穏やかに。

エフェクト：シネマティック・ウォームトーン（赤・金を強調）
冒頭フェードイン3秒・終盤フェードアウト3秒。
```
